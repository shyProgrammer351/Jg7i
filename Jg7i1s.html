문제

영어 단어를 입력하면 영한사전 파일을 열고 그 뜻을 찾아서 출력하는 문제입니다 이를 해결하는 다음 프로그램의 실행순서를 클릭하세요 
--------- 파일 dictionary.txt의 내용 --------- 
apple의 뜻은 사과입니다. 
banana의 뜻은 바나나입니다. 
carrot의 뜻은 당근입니다. 
dog의 뜻은 개입니다. 
egg의 뜻은 달걀입니다. 
fox의 뜻은 여우입니다. 

영어 단어를 입력하세요: banana
사전 이름을 입력하세요: C:\Users\user\Downloads\dictionary.txt
banana의 뜻은 바나나입니다.

프로그램 코드

	import java.io.*;

	import java.util.Scanner;

		

	public class DictionaryFile

	{

1		public static void main( String[] args ) throws IOException {

			Scanner scan = new Scanner( System.in );

			System.out.print( "영어 단어를 입력하세요: " );

2			String word = scan.next();

		

			System.out.print( "사전 이름을 입력하세요: " );

3			String filename = scan.next();

		

4			BufferedReader dictionary = new BufferedReader( new FileReader( new File( filename ) ) );

		

5			for ( String meaning = ""; ( meaning = dictionary.readLine() ) != null; ) {

6				if ( meaning.contains( word ) ) {

					System.out.println( meaning );

7					break;

				}

			}

		

8			dictionary.close();

			scan.close();

9		}

	}
